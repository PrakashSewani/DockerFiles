# DockerFiles

A collection of Docker Compose configurations and supporting files for services I use. Each service has a README beside its files with status and setup notes.

## Archived

- [Paperclip](archive/Paperclip/README.md): archived because the current Docker setup cannot route its Codex agent to the CommandCode custom provider with the agent's explicit local-login `CODEX_HOME`.

The Paperclip Compose files are retained for reference; its container and Docker data volume were removed. Local `.env` files are ignored by Git and are never published.
